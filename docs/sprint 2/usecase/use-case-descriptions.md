Use case: Searching Share prices

Actor: User

Main Sequence: 
1. User enters company name
2. User enters date range
3. The user submits the request.  
4. The system checks that the input is valid.  
5. The system retrieves the share price data (from storage or an external source).  
6. The system shows the results to the user.

View Price Chart 
1. The user selects the option to view the chart.  
2. The system processes the data.  
3. The system generates a visual chart.  
4. The system displays the chart to the user.  

Compare Two Companies
1. The user enters the first company.  
2. The user enters the second company.  
3. The user selects a date range.  
4. The user submits the comparison request.  
5. The system validates the inputs.  
6. The system retrieves data for both companies.  
7. The system compares the results.  
8. The system displays the comparison (usually as a chart).  

Save Price Data
1. The user selects the save option.  
2. The system stores the data locally (like on a file).  
3. The system confirms that the data has been saved.

Load Stored Data
1. The user selects the option to load stored data.  
2. The system retrieves the saved data.  
3. The system displays the data to the user.
